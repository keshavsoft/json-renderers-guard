json-renderers-guard / npx

Generate Starter Config Template

Instantly scaffold a clean, valid JSON configuration for any renderer project without installing dependencies.

Overview CLI Overview Generate Template Validate File Inspect Spec

How to Generate

Run the package with npx and redirect standard output to your desired JSON file:

npx json-renderers-guard > config.json

Generated Output Structure

The command outputs the canonical configuration structure with sensible defaults:

{
  "type": "table",
  "targetHtmlId": "",
  "data": [],
  "columns": [],
  "classToApply": "",
  "appendPosition": "replace",
  "showLog": false
}

Next Steps

  1. Open config.json and fill in your targetHtmlId, columns, and data.
  2. Validate your file using npx json-renderers-guard validate config.json.
