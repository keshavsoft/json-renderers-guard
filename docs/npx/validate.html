json-renderers-guard / npx

Validate Config Files with NPX

Check any JSON configuration file against GUARD's autonomous validators directly in terminal or CI/CD pipelines.

Overview CLI Overview Generate Template Validate File Inspect Spec

How to Validate

Pass the validate subcommand followed by the relative or absolute path to your JSON file:

npx json-renderers-guard validate my-config.json

Validation Results

When the configuration satisfies all schema constraints:

✓ Configuration in "my-config.json" is valid.

When a compulsory key is missing or invalid, an explicit error is printed and exit code 1 is returned:

✗ Validation failed for "my-config.json": Missing compulsory key: "targetHtmlId"

Use in NPM Scripts & CI/CD

Add file validation to your project's package.json test pipeline:

"scripts": {
  "test:config": "npx json-renderers-guard validate ./config/table.json"
}
