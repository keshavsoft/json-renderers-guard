NPX Command Line Interface

Run GUARD directly from your terminal with zero installation to scaffold templates, inspect schemas, and validate configuration files.

Quick Command Reference

Command Purpose
npx json-renderers-guard Outputs the canonical JSON configuration template to stdout.
npx json-renderers-guard > config.json Generates a valid starter template file in your current working directory.
npx json-renderers-guard validate <file> Validates any target JSON configuration file against GUARD contracts.
npx json-renderers-guard --spec Outputs the full JSON specification schema object.
npx json-renderers-guard --help Displays CLI usage instructions and available flags.

1. Generating Starter Templates

Quickly generate a canonical configuration template without writing it from scratch:

npx json-renderers-guard > my-table.json

2. Validating in CI / CD Pipelines

Ensure JSON fixtures and configuration files are valid before committing or deploying:

npx json-renderers-guard validate ./configs/table.json

Exits with code 0 on success (✓ Configuration is valid) or code 1 on failure.
