json-renderers-guard

NPX Command Line Interface

Run GUARD directly from your terminal with zero install to get templates, inspect specs, and validate files.

Quick Commands

CommandPurpose
npx json-renderers-guardOutputs the canonical JSON configuration template to stdout.
npx json-renderers-guard > config.jsonCreates a fresh, valid config file in your current folder.
npx json-renderers-guard validate <file>Validates a JSON configuration file against GUARD rules.
npx json-renderers-guard --specOutputs the raw schema specification object.
npx json-renderers-guard --helpDisplays usage instructions and available options.

Guides

  • Generating starter configuration templates
  • Validating configuration files in CI/CD and CLI
  • Inspecting specification and piping to tools
