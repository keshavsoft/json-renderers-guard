json-renderers-guard / npx

Inspect Specification with NPX

Output the raw schema object or pipe it into tools like jq, build scripts, or backend generators.

Overview CLI Overview Generate Template Validate File Inspect Spec

Inspect Command

npx json-renderers-guard --spec

Piping to jq

Filter specific fields directly in your shell:

# Extract allowed properties
npx json-renderers-guard --spec | jq 'keys'

# Extract default table type
npx json-renderers-guard --spec | jq '.type'

Use in Shell & Build Scripts

Fetch the latest schema dynamically into any toolchain without npm installing:

SPEC=$(npx json-renderers-guard --spec)
echo "Fetched spec: $SPEC"
