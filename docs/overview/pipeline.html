The four-repository pipeline

GUARD sits beside the four packages and is consumed where validation is required.

OverviewColumn contractValidation rulesExamplesConsumer migration
RepositoryResponsibility

Developer input → renderer configuration guard → component/build guard → JSON element spec → json-to-tag → browser DOM

The exact runtime order depends on the consuming application; the diagram shows responsibility boundaries.
