Build contract

  • type must be supported.
  • data must be an array.
  • For table types, columns must be an array.
  • Each column must be an object with a non-empty string columnName.
  • Each table data row must be an object.
  • When columns and data are non-empty, at least one column name must match a key in the first data row.

Renderer contract

Requires the documented top-level fields and their types, including a non-empty targetHtmlId.

Scope of the alignment check

The current rule checks for at least one match against the first row. It does not claim to validate every column against every row. Stricter behavior should be an intentional contract change with tests.

Error behavior

The V1 function returns true when accepted and throws an error for a failed check. Presentation of those errors belongs to the caller.
