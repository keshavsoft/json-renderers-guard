json-renderers-guard

Consumer migration

Consumers should redirect their existing guard entry points, not rewrite rendering internals.

OverviewColumn contractValidation rulesExamplesConsumer migration
  1. Publish or locally link json-renderers-guard.
  2. Add the package dependency to the consumer that needs the contract.
  3. Replace the duplicated guard implementation with an import from the package.
  4. Keep the existing call shape where practical and select the appropriate named contract.
  5. Run the guard tests and each consumer's build/tests.

The included consumer copies are local proposals. Nothing has been published to npm or pushed to GitHub by this archive.
