Valid table input

{
  "type": "table",
  "data": [{ "Name": "Keshav", "Designation": "Founder" }],
  "columns": [
    { "columnName": "Name", "width": "150px" },
    { "columnName": "Designation", "width": "100px" }
  ],
  "options": {},
  "showLog": false
}

Both column names appear in the data object. Width is supplied as optional table presentation information.

Invalid table input

{
  "type": "table",
  "data": [{ "Name": "Keshav" }],
  "columns": [{ "columnName": "MissingField", "width": "100px" }],
  "options": {},
  "showLog": false
}

The declared column does not match any key in the first data row, so the current alignment check rejects it.
